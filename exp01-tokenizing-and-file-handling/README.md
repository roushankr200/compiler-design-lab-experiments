# Experiment 1 - Concept of Tokenizing & File Handling

Aim: file handling in compiler construction, lexical-level text analysis,
token detection/classification, structured file manipulation and reporting.
Software: Python 3.8+

| File | Question |
|---|---|
| q1_analyze_text_file.py | Q1. Count lines, words, characters (no whitespace), blank lines in a file |
| q2_student_records_statistics.py | Q2. Store student records in a file; print average / highest / lowest marks |
| q3_delete_specified_lines.py | Q3. Delete specified line numbers (3 and 6) from a file |
| q4_copy_file_removing_comments.py | Q4. Copy file to file removing comment lines (#) |
| q5_basic_lexical_analyzer.py | Q5. Basic lexical analyzer - classify tokens: Keyword / Identifier / Literal / Operator / Delimiter |
| q6_remove_forbidden_words.py | Q6. Remove forbidden words (from drop.txt) from a file and generate report.txt with counts |

Run: `python3 q1_analyze_text_file.py` (etc.)
Sample files included: input.txt, source.txt, drop.txt, program.py
Note: Q3 edits input.txt in place and Q6 edits source.txt in place - re-download / restore the sample before re-running them.
